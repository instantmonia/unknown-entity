# UNKNOWN ENTITY

*An interactive philosophical game exploring the recognition of unfamiliar minds.*

## About

UNKNOWN ENTITY is an independent interactive game created in connection with the **2026 International Interdisciplinary Computational Cognitive Science Summer School (IICCSSS) Hackathon**.

Inspired by Professor Hong Yu Wong's lecture, *“How Do We Recognize an Alien Mind?”*, the project explores philosophical questions about how we identify and understand minds that may be fundamentally different from our own.

Although the project was not presented during the final Hackathon session, the game was completed independently.

## Development

The game was conceptualized and created independently using HTML, CSS, and JavaScript, with AI-assisted development through Claude Code.
